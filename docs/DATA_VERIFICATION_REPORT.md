# Veri Doğrulama Raporu

## Doğrulanmış bilgiler
- Marka adı, sanatçı adı, unvan, başlangıç yılı
- Adres, telefon, WhatsApp, e-posta, çalışma saatleri
- Sosyal medya (güncel Instagram), harita
- Hizmet listeleri, hijyen bilgileri, Sevgi İzi uygulama noktası ifadesi

## Sonradan eklenecek bilgiler
- Sertifika belge adları ve görselleri
- Google Place ID / API anahtarı
- GA4 / Google Ads / Meta Pixel ID
- Gerçek portföy dosyaları
- Gerçek Google yorumları
- Profesyonel nihai logo
- Hero kaynak görseli

## Kesinlikle uydurulmaması gerekenler
- Sertifika adı / belge numarası
- Müşteri sayısı, puan, yorum
- Ödül, kesin sağlık sonucu, fiyat, tedavi bilgisi, koordinat
